# Repository instructions

## Repository layout

- Keep MoonBit source files and package definitions under `src/`.
- Keep documentation under `docs/`.
- `README*.md`, `AGENTS.md`, and `CLAUDE.md` may remain outside `docs/`.
- Record missing features and follow-up work under `docs/issues/` instead of describing them in a README.

## README policy

README files describe only what the checked-in code can do and what users need to know to use it.

Do not put excuses, implementation-status framing, roadmaps, planned features, or aspirations in README files. When required functionality is missing, create an issue document under `docs/issues/`.

Treat wording such as "current", "MVP", "PoC", and "Phase" as a warning that the text probably belongs in an issue or design document rather than a README.
